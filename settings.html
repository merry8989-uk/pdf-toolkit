Diagnostics & logs

This log records what happens inside the app — tool runs, timings, and any errors — so a problem can be diagnosed without guesswork. It is written to this browser's own storage and never leaves your device: there is no server here to send it to. It is not shown anywhere else in the app, and nothing about it interrupts you. File contents are never recorded; file names are recorded only if you switch that on below.
