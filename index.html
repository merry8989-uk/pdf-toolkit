Common questions

Are my files really not uploaded?
Correct. The tools are plain HTML, CSS and JavaScript served as static files. Your file is read with the browser's File API into memory, processed there, and handed back as a download. There is no backend endpoint for files to reach.
Is there a file-size limit?
There is no server limit. The practical ceiling is your device's available memory — very large PDFs may be slow on low-RAM phones. Splitting big documents first usually helps.
Which tools are not here, and why?
High-fidelity Office⇄PDF conversion (Word/Excel/PowerPoint) and AI summarising/translation need a desktop-class engine or a model server, neither of which can run in a browser tab. They are left out rather than offered badly.
How does OCR work without a server?
The OCR tool uses Tesseract, compiled to WebAssembly, running in a background worker in your browser. The language data is bundled with the site, so even OCR happens offline.
