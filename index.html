Why a browser-only toolkit is better for you

🔒Private by architecture
Most online PDF sites upload your file to their servers. Here there is no server to upload to — the code runs in your tab. Open the Network panel and watch: nothing goes out.
⚡Instant
No upload, no queue, no download round-trip. The moment you click, your own CPU does the work.
🪶Free, and it stays free
There are no per-file server bills to cover, so there is no paywall and no watermark stamped onto your output.
🧩Open and inspectable
A static site with the libraries vendored locally and no third-party requests. View source, read the code, verify the claim.

Common questions

Are my files really not uploaded?
Correct. The tools are plain HTML, CSS and JavaScript served as static files. Your file is read with the browser's File API into memory, processed there, and handed back as a download. There is no backend endpoint for files to reach.
Is there a file-size limit?
There is no server limit. The practical ceiling is your device's available memory — very large PDFs may be slow on low-RAM phones. Splitting big documents first usually helps.
Which tools are not here, and why?
High-fidelity Office⇄PDF conversion (Word/Excel/PowerPoint) and AI summarising/translation need a desktop-class engine or a model server, neither of which can run in a browser tab. They are left out rather than offered badly.
How does OCR work without a server?
The OCR tool uses Tesseract, compiled to WebAssembly, running in a background worker in your browser. The language data is bundled with the site, so even OCR happens offline.
Can I install it as an app?
Yes. Use the Install app button in the footer (or your browser's Install app / Add to Home screen menu). A service worker caches the app and its engines, so the tools keep working offline after your first visit. You can also download the whole source from the footer and run it yourself — there is no build step.
Can I request a tool that isn't here?
Please do — ideas and bug reports are welcome on Instagram at @osintgram_io. Tools that need AI models (true AI background removal, skin retouch, AI upscaling) currently ship as honest, model-free approximations.
